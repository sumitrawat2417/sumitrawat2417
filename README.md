## 🛠️ What I Build
- ⚡ **Embedded Systems & Firmware:** Microcontroller OS kernels (ESP32-S3), custom display drivers (`TFT_eSPI`), power management, dirty-rectangle rendering pipelines.
- 📱 **Hardware-Software Integration:** Bridging bare-metal devices to mobile apps via BLE GATT & HID, Wi-Fi, and ESP-NOW.
- 💻 **Offline-First Software:** Local data persistence, React-based Point-of-Sale (ManSula Nexus), and high-performance UI/UX.
