## Signature Projects

### ManSula Business OS — *flagship project*
A full business-operations SaaS, built as a React PWA so it works across devices. In active development and real-world use for over 2 years. A growing base of local store and business owners run parts of their operations on it — and I'm one of them: I run a food cart, and ManSula BOS is what I use to run it. It's thoroughly documented, which has made it possible to keep extending it steadily rather than rebuilding from scratch each time.

### ManSula Smart Terminal — *in progress*
A dedicated hardware point-of-sale device built on the ESP32-S3, designed to run the same business logic as ManSula BOS but on its own physical terminal rather than as an app. Planned features include voice payment announcements, dynamic QR code generation, real-time payment confirmation, a loyalty card system, and a local wallet system. Currently in development.

### MapLok
A premium local-business discovery platform — think a focused, business-first take on the "maps + reviews" model. Lets customers find nearby stores, see ratings, images, and directions, and contact the business directly, while giving business owners an online presence without needing their own website. Built solo in about a month. Development paused once the core architecture and flow were solid — the interest was in proving the concept and getting the structure right, not in immediately shipping a finished product. Left in a genuinely premium-feeling, well-architected state.

### DivSum Ecosystem — OS, Watch & Connect
A self-built smartwatch platform, developed from the ground up:
- **DivSum OS** — a custom operating system for wearables
- **DivSum Watch** — the physical smartwatch hardware, built on ESP32-S3
- **DivSum Connect** — the companion mobile app that pairs with the watch

Built entirely independently — firmware, hardware integration, and companion software — without a team or existing framework to lean on.
